### 🩺 1. Health Track — Acompanhamento de Saúde

Aplicação web desenvolvida como projeto final do curso **CS50 Web Programming with Python and JavaScript**, com o objetivo de permitir que usuários registrem e acompanhem informações relacionadas ao seu índice de massa corporal (IMC). Atualmente estou tentando implementar novas funcionalidades, como por exemplo, utilizar os IMCs salvos como referência para o sistema sugerir alimentos e exercícios para os usuários de acordo com a sua situação.

**Principais funcionalidades:**
- Cadastro e autenticação de usuários.
- Registro de peso e altura com cálculo de IMC.
- Histórico de registros para acompanhamento da evolução.

**Tecnologias usadas:**
- Python
- Django
- HTML e CSS
- Um pouco de JavaScript

🔗 **Repositório:** https://github.com/IordanValerio/healthtrack.git

### 🐾 2. Adota Aí — Sistema de Adoção de Animais

Projeto voltado à organização e consulta de informações sobre animais disponíveis para adoção. A aplicação foi desenvolvida em grupo para a disciplina de Python no primeiro período do curso de Análise e Desenvolvimento de sistemas. Esse projeto representa a evolução do nosso grupo na disciplina, pois inicialmente o sistema rodava em terminal, onde o usuário podia interagir com ele através de um menu interativo (feito com o loop While e condicionais). Mas em seguida transformamos o sistema em um site, substituímos os inputs por formulários e usamos ferramentas como HTML, CSS e Flask para criar a interface. Também destaco o uso de arquivos CSV e XML, que servem como o banco de dados do sistema.

**Objetivo:** Facilitar a consulta de informações sobre animais e organizar os dados relacionados à adoção.

**Tecnologias usadas:**
- Python
- Flask
- Pandas
- CSV e XML
- HTML e CSS

🔗 **Apresentação:** https://youtu.be/GaXgSBUnuTk

OBS: Optamos por deixar esse repositório em particular como privado. Mas se quiserem analisar o código posso adicioná-los como colaboradores.
